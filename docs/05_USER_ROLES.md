# User Roles

## 1. Farmer / Collector
Can:
- Register collection events
- Capture GPS
- Submit species
- Submit quantity
- View own collection history

Cannot:
- Modify laboratory results
- Modify manufacturer information
- Approve own quality results

## 2. Processor
Can:
- Receive batches
- Record custody transfer
- Record processing events
- Update processing status

## 3. Laboratory
Can:
- Receive samples
- Record quality tests
- Upload certificate references
- Submit test results

## 4. Manufacturer
Can:
- Receive validated material
- Create formulation batches
- Create product records
- Generate QR codes
- Initiate recalls

## 5. Administrator
Can:
- Manage users
- Manage approved harvesting zones
- Manage system configuration
- Review suspicious events
- Trigger administrative actions

## 6. Consumer
Can:
- Scan QR
- View product provenance
- View verification status
- View recall warnings

Consumer does not need an account.
